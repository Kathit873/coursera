# Paradise Nursery

A React + Redux shopping cart app for a plant nursery, built for the Coursera capstone lab.

## Setup

```
npm install
npm run dev
```

## Before deploying

1. In `vite.config.js`, change `base: "/YOUR_REPOSITORY_NAME"` to match your actual GitHub repo name.
2. In `package.json`, update the `homepage` field with your GitHub username/repo name.

## Deploy to GitHub Pages

```
npm install gh-pages --save-dev
npm run deploy
```

Then in your GitHub repo: **Settings → Pages → Branch: gh-pages → Save**.
